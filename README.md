# Economia Circular Udp

Implement exactly the screenshot and nothing else

> **Rama `individual`**: esta rama contiene la versión del simulador para **clientes individuales que pagan** (sin equipos, sin rondas programadas, autoregistro, progreso secuencial a su propio ritmo, y un administrador superusuario). Está pensada para vivir, a futuro, en su propio repositorio (`economia-circular-individual`); mientras ese repo se crea, el trabajo queda en esta rama sin tocar `main`, que sigue siendo la versión multi-equipo original conectada a Lovable.

This project was built with [Lovable](https://lovable.dev).
